このプロジェクトディレクトリ（`/Users/doiyuma/Documents/Claude/Projects/NTT西/`）は、ユーザーの就職活動（セキュリティエンジニア/セキュリティインターンシップ志望）のES（エントリーシート）作成用。

- 直下の `ES.md` が現在作成中の企業（NTT西日本）のES設問。
- 兄弟ディレクトリ `KDDI/`、`NTTドコモ/`、`ソフトバンク/` に、同種の設問（強み・技術スキル・資格・CTF等の課外活動・志望動機）への既存の回答・自己PR資料・スキルチェックシートが多数保存されている。これらは他社宛だが、事実（資格名・スキル・CTF実績・強みのエピソード）は使い回せるため、新しい企業のESを書く際はまずこれらのフォルダを調査し、事実ベースで新設問向けに調整するのが効率的。
- 特に情報密度が高いファイル例: `ソフトバンク/ソフトバンク スキルチェックシート 記述ver7.md`（最新版・技術スキル詳細）、`KDDI/KDDI ES ver1.md`（自己PRの下書き集）、`NTTドコモ/私の軸_整理資料.md`（強み・価値観の整理）、`NTTドコモ/想定質問100_回答集.md`（想定QA集、大容量）。

**Why:** ユーザーは同じ経歴・スキル・資格・CTF実績を複数社のESで使い回しており、ゼロから聞き出すのではなく既存ファイルから一次情報を集めて再構成するのが正しいアプローチ。
**How to apply:** 新しい企業向けESや自己PR作成を頼まれたら、まずこのプロジェクト内の他社フォルダをgrep/読み込みして事実を集め、捏造しないこと。文字数制限（140字等）に合わせて既存の表現を調整する。
